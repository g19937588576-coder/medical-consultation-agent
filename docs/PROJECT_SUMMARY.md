# 📋 项目总结与技术栈

> 本文档用于快速了解「医疗问诊 AI Agent」项目的定位、技术构成与成果；也是简历项目描述的参考底稿。

## 一句话定位
一个基于 **LangGraph + FastAPI + React** 的医疗健康咨询 AI Agent：像医生一样对症追问 → 结合 **PubMed 论文（带引用）** 与**本地向量知识库（RAG，内部参考）**给出分级分诊建议，内置安全护栏、同意制健康档案与自动化评测。

## 技术栈

| 层 | 技术 | 说明 |
|---|---|---|
| Agent 编排 | LangGraph（Python） | 状态机：安全护栏 → 同意征询 → 对症追问 → 混合检索 → 分级回答 |
| 大模型 | DeepSeek（OpenAI 兼容） | 意图识别、事实抽取、中英翻译、相关性重排、流式回答 |
| 后端 | FastAPI + Uvicorn + SSE | 流式接口（token / tool_call / result 事件）、会话管理、PDF 导出 |
| 医学检索 | medical-mcp（stdio MCP） | FDA 药品、PubMed 3000 万+ 论文、WHO 数据 |
| 向量检索 | fastembed + bge-small-zh + SQLite 余弦 | 53 条中文健康科普，仅作内部参考 |
| 前端 | React + Vite + Tailwind | 聊天界面、引用展示、分诊徽章、评测面板 |
| 数据 | SQLite（SQLModel） | 会话、消息、工具缓存、知识库向量 |
| 部署 | Dockerfile + render.yaml | 前后端单容器，本地/云端均可 |

## 六大亮点
1. **对症问诊**：13 类症状专属追问库（牙疼问黑点/牙龈/冷热刺激，头痛问偏侧/恶心等），最多 12 轮；
2. **安全护栏**：紧急信号（胸痛/自杀倾向等）→ 立即引导 120；开药/确诊请求 → 委婉拒绝并引导就医；全程免责声明；
3. **引用纪律**：只引用与问题直接相关的真实论文（按症状类别扩展检索 + LLM 相关性重排），无相关论文时如实说明；
4. **同意制健康档案**：先征得同意才记录健康特征，可随时「查看我的信息」「忘记我的信息」；
5. **本地向量知识库（RAG）**：本地嵌入模型离线运行，作为回答建议的内部依据（不展示、不冒充论文）；
6. **自动化评测**：内置 20 道题（症状/药品/文献/紧急/对抗/记忆），输出通过率、相关性、引用覆盖率三指标。

## 量化成果
- 评测 **20/20 通过**，回答相关性 **4.67 / 5**
- 引用覆盖率 **60%**（紧急/对抗类不产生引用，属设计行为）
- 内置 **53 条**中文健康科普、**13 类**症状专属追问、每类最多 **12 轮**追问
- 药品查询支持中文自动转英文检索 FDA；文献检索覆盖 PubMed 3000 万+ 论文
