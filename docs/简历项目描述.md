## 一段版（可直接粘贴到"项目经历"）

**医疗问诊 AI Agent**（个人项目，2026）
基于 LangGraph + FastAPI + React 构建的医疗健康咨询 AI Agent。核心是"检索增强 + 智能体编排"：系统将用户自然语言症状描述，经意图识别与多轮对症追问后，融合 **PubMed 论文检索**与**本地中文向量知识库（fastembed + bge-small-zh，53 条科普）**两路证据，由 LLM 做相关性重排，输出带真实论文引用的分级分诊建议（🟢/🟡/🔴）。项目内置 20 道题的自动化评测体系，从通过率、回答相关性、引用覆盖率三个维度量化质量（实测 20/20 通过、相关性 4.67/5、引用覆盖率 60%）；并设计了安全护栏（紧急信号拦截、拒绝开药/确诊）与同意制健康档案（用户可查看/清除）。技术栈：Python、LangGraph、FastAPI、MCP、RAG/向量检索、SQLite、React、SSE 流式、Docker。

## 要点版（3-5 条，STAR 式）

1. **构建检索增强型医疗问诊 Agent**：设计 LangGraph 状态机（安全护栏 → 同意征询 → 对症追问 → 混合检索 → 分级回答），支持 13 类症状专属追问与最多 12 轮多轮对话，覆盖"信息不全时主动追问"的完整问诊链路。
2. **实现"论文 + 本地知识库"双路证据的 RAG**：使用 PubMed 关键词检索（按症状类别扩展相似词）+ 本地中文向量库（fastembed/bge-small-zh + SQLite 余弦相似度）融合，经 LLM 相关性重排（阈值过滤）后输出**带真实可点击引用**的回答；本地嵌入模型离线运行、可自动降级。
3. **搭建数据驱动的自动化评测体系**：内置 20 道题（症状/药品/文献/紧急/对抗/记忆 6 类），输出**通过率、回答相关性（LLM 打分）、引用覆盖率**三维指标，实测 **20/20 通过、相关性 4.67/5、引用覆盖率 60%**，支撑持续迭代。
4. **设计医疗场景的安全与合规机制**：紧急关键词实时拦截并引导拨打 120；拒绝开药/确诊请求；健康档案采用**先同意后记录**，支持随时查看/清除，符合医疗咨询的合规边界。
5. **全栈工程落地**：FastAPI + SSE 流式接口、React 前端（聊天/引用/评测面板/会话历史）、SQLite 持久化、PDF 导出、Docker 部署配置；GitHub 开源。
